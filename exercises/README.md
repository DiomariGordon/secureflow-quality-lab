# SecureFlow Exercises

Complete these in order. Each exercise should use a separate Git branch after the baseline is published.

## Exercise 1 — Boundary-value ownership

File: [`01-risk-boundary.md`](01-risk-boundary.md)

Learn how requirements become boundary tests and how a small rule change propagates through evidence.

## Exercise 2 — Authorization design

File: [`02-auditor-role.md`](02-auditor-role.md)

Add an auditor role that can read records and audit events but cannot create, submit, or approve.

## Exercise 3 — Negative authentication behavior

File: [`03-login-rate-limit.md`](03-login-rate-limit.md)

Design a controlled failed-login rate limit, including reset behavior and audit evidence.

## Exercise 4 — CI evidence

File: [`04-ci-evidence.md`](04-ci-evidence.md)

Publish HTML/trace evidence and learn how a quality gate communicates failure.
